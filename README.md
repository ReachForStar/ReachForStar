# 摘星

AI 编码 Agent 探索者 · 摘星输入法作者

## 公开项目

- **[pi-weixin-bridge](https://github.com/ReachForStar/pi-weixin-bridge)** — 微信 ClawBot ↔ pi 桥接服务，iLink 协议直连，pi SDK 同进程接入
- **[excalidraw-tools-mcp](https://github.com/ReachForStar/excalidraw-tools-mcp)** — 面向 AI Agent 的 Excalidraw 画布工具，MCP server（stdio + Streamable HTTP）与 cordis plugin
- **[dsh-client-ui-polish](https://github.com/ReachForStar/dsh-client-ui-polish)** — DeepSeek Harness 客户端增强插件集：界面美化、会话统计、Excalidraw 工具、pi 子代理与 AMAX 模型接入
- **[reachforstar-llm-wiki](https://github.com/ReachForStar/reachforstar-llm-wiki)** — LLM Wiki 知识库模式与 wiki-memory hook，自动建库、注入导航、qmd 检索
- **[amax](https://github.com/ReachForStar/amax)** — AMAX Dashboard，展示账户当日 Token 消耗、费用与剩余额度
- **[dnsopt-swift](https://github.com/ReachForStar/dnsopt-swift)** — DNS 批量测速与一键切换，支持 DoH、污染检测与时序监控

## 私有项目

- **摘星输入法** — 基于 Fcitx5 的 Linux 本地中文输入法，支持全拼、小鹤双拼、模糊音、个人学习与离线联想
- **monitorctl** — 跨平台显示器管理软件，通过 DDC/CI 控制亮度、对比度、音量与输入源
- **MirrorFlow** — HarmonyOS 投屏、远程控制与文件互传工具

## 技术栈

`Rust` `TypeScript` `Python` `Tauri` `Fcitx5`
